# Der 7-Minuten-Fall

Format-Konzept für einen 7-minütigen Krimi, bei dem die Zuschauer den Täter
ermitteln sollen — Minutenplan, Fair-Play-Regeln und Werkzeug-Stack.

**Konzept:** [`konzept/7-minuten-krimi.html`](konzept/7-minuten-krimi.html)

## Kern des Formats

- **420 Sekunden**, 8 Beats. Über die Hälfte der Laufzeit gehört der Beweisführung.
- **Zwei-von-Drei-Matrix:** Jeder Verdächtige wird an Motiv, Gelegenheit und Spur
  gemessen. Der Täter erfüllt alle drei, jeder Unschuldige exakt zwei.
- **Eine versteckte Zelle:** Genau eine Matrix-Zelle wird nie direkt gezeigt und
  muss aus zwei weit auseinanderliegenden Fakten geschlossen werden. Das ist das
  Rätsel; alles andere ist Kulisse.
- **Der Cut bei 5:30:** Ab hier keine neue Information mehr. Härteste Regel.
